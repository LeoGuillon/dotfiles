### Text objects and surrounds

## `<leader>`-base mappings

- `n` : [n]ew…
  - `b` : base
  - `c` : canvas
  - `n` : note
- `i` : [i]nsert…
  - `c` : [c]allout
  - `h1` : [h]eading 1
  - `k` : wiki lin[k]
  - `t` : [t]emplate (from templater)
  - `u` : [u]rl
  - `v` : code block (for de[v]eloppement)
- `s` : [s]earch…
  - `c` : [c]ommand (= open command palette)
  - `f`/`n`/`r` : file/note/recent (=open quick switcher)
  - `h` : [h]otkeys for plugin
  - `l` : workspace [l]ayout
  - `p` : [p]lugin
  - `,` : settings for plugin (inspired from ⌘, macOS usual keyboard shortcut)
- `o` : [o]pen…
  - `c` : [c]allouts
  - `f` : [f]lashcards
  - `g` : [g]raph view
  - `p` : [p]rojects
  - `r` : [r]andom note
  - `,` : [s]ettings
- `t` : [t]oggle…
  - `b` : [b]olded text
  - `e`/`l` : file [e]xplorer/[l]eft sidebar
  - `n` : [n]umbered list
  - `r` : [r]ight sidebar
  - `s` : [s]tatus bar
  - `t` : [t]ab bar
